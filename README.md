# Sonoran Pomodoro Clock 🌵

A beautiful, chill Pomodoro timer inspired by the Sonoran Desert and the Claude code icon aesthetic.

![Pomodoro Timer](https://img.shields.io/badge/Pomodoro-Timer-orange?style=for-the-badge)

## Features

- **Customizable Presets**: Choose from popular work/break intervals:
  - 25 min / 5 min break (classic Pomodoro)
  - 50 min / 10 min break
  - 45 min / 15 min break
  - 30 min / 5 min break
  - 15 min / 3 min break
  - 90 min / 20 min break (deep work)

- **Desert-Inspired Design**: 
  - Warm sunset gradients (orange, terracotta, dusty rose)
  - SVG Sonoran desert scene with saguaro cacti and mountains
  - Claude icon-style geometric shapes with smooth morphing animations

- **Timer Features**:
  - Visual circular progress ring
  - Session counter (tracks 4 pomodoros)
  - Audio notifications (gentle tones)
  - Browser notifications (optional)
  - Auto-switches between work and break modes

- **Keyboard Shortcuts**:
  - `Space` - Play/Pause
  - `R` - Reset timer
  - `S` - Skip to next session

## Usage

Simply open `index.html` in any modern web browser. No build tools or dependencies required!

```bash
# Open directly in browser
open index.html

# Or serve locally
python -m http.server 8000
# Then visit http://localhost:8000
```

## Design Philosophy

The design draws inspiration from:
- **Sonoran Desert**: Saguaro cacti, desert mountains, warm sunset colors
- **Claude Code Icon**: Geometric shapes, rounded forms, minimalist aesthetic
- **Chill Vibes**: Soft gradients, smooth animations, relaxing color palette
