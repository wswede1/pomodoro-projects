# Sonoran Pomodoro

Customizable Pomodoro clock with a chill Sonoran-desert-inspired design.

## Features

- Preset dropdowns (e.g. 50/10, 25/5, 52/17)
- Custom work/break durations (editable while paused)
- Start/pause/reset/skip
- Auto-switches between work and break
- Rad “vibes” UI: desert dusk gradient, dunes, saguaro silhouettes, glowing progress ring

## Run locally

```bash
npm install
npm run dev
```

## Install on iPhone (Add to Home Screen)

- Deploy it somewhere **over HTTPS** (required for full PWA/offline support).
- Open the deployed site in **Safari** on iPhone.
- Tap **Share** → **Add to Home Screen**.

## Build

```bash
npm run build
npm run preview
```
